## 📝 Overview
**Texas Roll ’Em** is a roguelike dice-rolling strategy game built in Godot.  
Face randomized enemy waves, battle unique bosses, and earn rewards in a Wild West pixel-art adventure.  
The game combines tactical decisions, luck, and resource management for a tense but fun experience.

---

## ✨ Features
- Procedurally generated enemy waves  
- Boss encounters with unique mechanics  
- Pixel-art combat with upgradeable abilities and power-ups  
- Turn-based dice mechanics rewarding strategy

## 📂 Repository Structure
```
scripts/
  wave_manager.gd       # Handles enemy wave progression
  boss.gd               # Controls boss behaviors and patterns
  player.gd             # Manages player dice rolls and actions
assets/
  sprites/              # Game sprites and tiles
  UI/                   # Interface graphics
scenes/
  main.tscn             # Main gameplay scene
```

---

## 🔍 Code Highlights
- **wave_manager.gd** – Modular system generating enemy waves while balancing difficulty  
- **boss.gd** – Handles boss AI and attack patterns for varied encounters  

---

## 🚀 How to Run
```
git clone https://github.com/mosswyrm/texas-roll-em.git
```

1. Open in **Godot (version X.X)**  
2. Press **Play**  

Or [play it online on Itch.io](https://mosswyrm.itch.io/texas-roll-em)
